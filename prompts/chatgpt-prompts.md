# Prompts para produzir ebooks com IA

## 1. Ideacao do tema

Use este prompt para encontrar um recorte bom de ebook:

```text
Crie 5 ideias de ebook sobre [tema principal].
Cada ideia deve incluir:
- titulo curto
- promessa principal
- publico ideal
- nivel de dificuldade
- diferencial do material
Mantenha foco pratico e linguagem clara.
```

## 2. Estrutura editorial

```text
Monte a estrutura de um ebook sobre [tema].
Quero:
- titulo
- subtitulo
- publico-alvo
- tom editorial
- 4 a 6 capitulos
- objetivo de cada capitulo
- CTA final
Evite capitulos genericos e mantenha sequencia logica.
```

## 3. Escrita de capitulo

```text
Escreva um capitulo de ebook sobre [topico].
Regras:
- explicacao simples
- texto enxuto
- contexto real de uso
- 3 pontos-chave
- 1 exemplo de codigo
- fechamento com recomendacao pratica
Escreva em portugues do Brasil.
```

## 4. Prompt de capa

```text
Crie um prompt visual para capa de ebook sobre [tema].
Inclua:
- estilo visual
- paleta
- atmosfera
- tipografia
- elemento central
- frase principal da capa
```

## 5. Revisao final

```text
Revise o texto abaixo como se voce fosse um editor tecnico.
Quero:
- cortes de repeticao
- frases mais claras
- melhoria de fluidez
- alerta de partes vagas
- sugestoes de exemplos melhores
Nao reescreva tudo do zero sem necessidade.
```
