# Workflow recomendado

## Objetivo

Usar IA como apoio de producao, sem perder controle editorial.

## Fluxo sugerido

1. Defina o recorte do ebook com ajuda de IA.
2. Estruture titulo, promessa e capitulos.
3. Gere rascunhos por capitulo com prompts menores.
4. Passe o conteudo para `examples/css-selectors-book.json` ou para uma copia dele.
5. Rode o gerador para obter Markdown e HTML.
6. Revise linguagem, exemplos e coerencia tecnica.
7. Use o HTML como base para publicacao, landing page ou conversao futura para PDF.

## Papel de cada ferramenta

- ChatGPT ou outro modelo generativo: ideacao, estrutura, rascunho e variacoes.
- GitHub Copilot: refinamento do codigo, exemplos tecnicos e ajustes em arquivos.
- Revisao manual: clareza, exatidao e consistencia do material.

## Boas praticas

- mantenha um arquivo fonte estruturado
- prefira capitulos curtos e progressivos
- use exemplos reais
- revise sempre antes de publicar
- trate a IA como acelerador, nao como aprovador final
